I ran as many of the ABS CDO portfolios we had in our database and added them to the ever-growing list of
work that Stu and Annie have been doing manually. Attached are the results. We now have credit model
analysis for 92 different ABS CDOs. I've sorted them two ways on two different tabs. First, sorting from best to
worst by implied writedown, and, then sorting from best to worst by the weighted avg fair value of the covered
portfolio. I've highlighted KLiO I and TALLSHlPS in green as you'll see for obvious reasons.
We're going to continue to add to this list and also have plenty more work to be done as far as creating a
principal writedown WAL (rather than start date), automating the whole process, etc... But, I think it's a great
start and thanks again to everyone who has been working very hard to get this done in short order.
